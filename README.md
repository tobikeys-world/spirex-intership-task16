InternLink — Student Internship Portal

InternLink is a responsive student internship portal built with HTML, CSS, and JavaScript. It allows students to explore internship opportunities, view detailed information, submit applications, and track their applications through an interactive dashboard.

This project was developed as part of my SpireX Foundation Frontend Development Internship — Task 16.

📌 Project Overview

Finding suitable internship opportunities can be challenging for students. InternLink provides a simple and user-friendly interface where students can discover opportunities and manage their applications from one place.

The project focuses on creating a functional frontend experience rather than a static webpage.

✨ Features

- 🔎 Search internship opportunities
- 📍 Filter internships by location
- 💼 Browse available internship opportunities
- 📄 View detailed internship information
- 📝 Complete an internship application form

  - Full name
  - Email address
  - Phone number
  - Institution
  - Course / field of study
- ✅ Application confirmation
- 🚫 Duplicate application protection

⚙️ How It Works

1. Explore Internships

Students can browse available internship opportunities and view information such as:

- Job title
- Company
- Location
- Duration
- Required skills

2. Search and Filter

The search field allows users to find internships by title or company.

The location filter allows users to narrow opportunities by:

- Remote
- Lagos
- Abuja

3. View Internship Details

Clicking View & Apply opens a detailed internship modal containing information about the opportunity.

4. Submit an Application

Students can complete the application form with their personal and academic information.

The application is validated before submission.

5. Track Applications

After submission, the application appears in the Application Tracker.

Application information is stored in the browser using "localStorage", allowing it to remain available after refreshing the page.

6. Save Opportunities

Students can bookmark internship opportunities using the heart icon. Saved internships are also stored locally.
